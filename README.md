TetrisPy 🎮

A professional Tetris clone built with Python and Pygame featuring multiple difficulty levels, high score tracking, and particle effects.

Features ✨

    🎯 Multiple Difficulty Levels: Easy, Medium, Hard, Extreme

    🏆 Persistent High Scores: Automatic saving and loading

    💫 Visual Effects: Particle systems for line clears

    🎨 Professional UI: Smooth animations and clean interface

    ⚙️ Configurable Controls: Customizable key bindings

    📊 Game Statistics: Score, level, lines cleared tracking

Installation 🚀
Prerequisites

    Python 3.8 or higher

    pip package manager

Method 1: From Source
bash

# Clone the repository
git clone https://github.com/seu-usuario/TetrisPy.git
cd TetrisPy

# Install dependencies
pip install -r requirements.txt

# Run the game
python run.py

Method 2: Using pip (after publishing)
bash

pip install tetrispy
tetrispy

Gameplay 🎮
Controls

    ← →: Move piece left/right

    ↑: Rotate piece

    ↓: Soft drop (accelerate fall)

    Space: Hard drop (instant fall)

    ESC: Pause/Return to menu

    Enter: Select menu options

Scoring System

    1 line: 100 × level

    2 lines: 300 × level

    3 lines: 500 × level

    4 lines (Tetris): 800 × level
